# 🍵 Mandatory MATCHA BAR - POS & Sales Analytics System

An aesthetic, modern, Japanese minimalist Point of Sale (POS) and Sales Analytics Web Application tailored specifically for **Mandatory MATCHA BAR**.

---

## 🍵 Aesthetic & Branding
- **Design Inspiration**: Minimalist Japanese matcha bar aesthetic with warm buttermilk cream canvas (`#FDF8EE`), ceremonial matcha green (`#2C4A2E`, `#3A5A40`), matcha foam accents (`#E8F0E4`), toasty pastry hues (`#D4A373`, `#C58F49`), and signature checkered border trim.
- **Typography**: Elegant editorial serif (`Playfair Display`) paired with clean modernist monospace (`DM Mono`) for currency prices.
- **Brand Mascot**: Stretching cat logo `🐈‍⬛`.
- **Currency**: Philippine Peso (`₱` PHP).
